# Sayward Design System

## Concept

Source of truth: `sayward-concept.png` at 1536 × 1024.

The interface is an editorial writing desk: quiet paper, deep ink, a single vermilion action color, and a strong rule separating the input rail from the generated manuscript.

## Tokens

- Paper: `#f8f5ee`
- Deeper paper: `#efe9dc`
- Ink: `#0c213f`
- Soft ink: `#435166`
- Rule: `#bfc2c5`
- Accent: `#df351f`
- Serif: Georgia stack
- Interface sans: Geist stack
- Corners: 5–6px
- Motion: 140–160ms, disabled for reduced-motion users

## Container and component rules

- Desktop uses a 42/58 split with one vertical rule.
- Mobile stacks composer above manuscript at 820px.
- Repeated elements are open sections, not card grids.
- Scenario selection uses an underline; tone selection uses a filled ink segment.
- Output is large serif text with copy controls on the section rule.
- Locked material fades into a single purchase band.
